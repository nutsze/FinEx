# FinEx

Тренажёр для подготовки к экзамену на статус квалифицированного инвестора (экзамен Московской биржи на платформе «Финуслуги»).

## Что внутри

- **Темы и теория** — 6 блоков программы, 25 уроков с формулами и примерами.
- **Практика** — 153 вопроса с одним или несколькими верными ответами и разбором; режим работы над ошибками.
- **Расчётные задачи** — 26 типов задач со случайными числами и пошаговым решением.
- **Лаборатория** — конструктор опционных стратегий с графиком выплат и калькулятор облигаций (цена, доходность, дюрация).
- **Торговый тренажёр** — учебный счёт, вымышленные акции, облигации и фьючерсы; НКД и купоны, плечо, НПР1/НПР2, маржин-колл, вариационная маржа, задания.
- **Демоэкзамен** — 50 вопросов, 60 минут, проходной балл 35 (70%), разбор по темам, история попыток.

Прогресс хранится локально на компьютере.

## Установка

Скачайте `FinEx.exe` со страницы [Releases](../../releases) и запустите. Установка не требуется.
Нужна Windows 10/11 с компонентом Microsoft Edge WebView2 (в Windows 11 он есть по умолчанию; если его нет, приложение предложит установить).

Windows SmartScreen может предупредить о неподписанном приложении: «Подробнее» → «Выполнить в любом случае».

## Сборка из исходников

Стек: Go + [Wails v2](https://wails.io) (нативное окно на WebView2), интерфейс — HTML/CSS/JavaScript без сборщика.

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.10.2
```

```bash
wails build -platform windows/amd64 -skipbindings
```

Готовый файл: `build/bin/FinEx.exe`. Интерфейс можно открыть и без сборки — файл `frontend/index.html` в браузере.

## Структура

```
main.go                     окно приложения, встраивание frontend/
frontend/index.html         каркас
frontend/css/app.css        оформление (светлая и тёмная темы)
frontend/js/core.js         состояние, хранение, маршрутизация
frontend/js/app.js          обзор, темы, практика, задачи, экзамен
frontend/js/lab.js          лаборатория и графики
frontend/js/sim.js          торговый тренажёр
frontend/js/data/           теория, вопросы, генераторы задач
```

## Важно

Теория и вопросы составлены самостоятельно по открытой программе экзамена и не совпадают с официальной базой вопросов. Нормативные пороги и условия экзамена меняются — сверяйтесь с актуальными документами Банка России и страницей экзамена. Приложение не является инвестиционной рекомендацией.
